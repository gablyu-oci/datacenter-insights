# AI Insights Tab — Mail-App 2-Column Refactor: Component Architecture

Status: Design for live demo TODAY. Lean and prescriptive.
Scope: `frontend/src/components/tabs/ai-insights/` only. Reuse existing hooks verbatim.

## 1. Component tree (post-refactor)

```
AIInsightsTab
├── <header /> (unchanged: title, AutoGeneratedBadge, Run-again button, banners)
└── <div grid 320px 1fr>            (only when showSnapshot === true)
    ├── InsightSidebar (left col, 320px)
    │   ├── Group "Today" — Collapsible, default open
    │   │   └── SidebarRow[] from latest.data.insights
    │   ├── Group "Saved" — Collapsible, default open if total>0
    │   │   └── SidebarRow[] from useSavedInsights()
    │   └── Group "Past Runs" — Collapsible, default closed
    │       └── PastRunSessionRow[] (toggle expands to nested SidebarRow[])
    └── InsightDetailPane (right col, 1fr)
        └── InsightCard (existing, unchanged)
```

## 2. State ownership

`AIInsightsTab` owns:
- `selectedInsightId: string | null` — defaults to `latest.data?.insights[0]?.id ?? null`.
- `insightLookup: Record<string, LatestInsight>` — merged from (a) latest snapshot insights, (b) saved insights cache, (c) past-run insights cache. Sidebar populates this as it lazy-loads.
- `savedOverrides: Record<string, boolean>` — optimistic Save toggle from the detail pane flips the sidebar row's saved indicator without refetching.

`InsightSidebar` owns:
- Per-group open/closed state (delegated to `Collapsible`).
- Per-past-run-session expansion state and per-session insight cache (same shape as today's `PastRunsSection`).

Sidebar exposes `onSelect(insightId, fullInsight)` so the parent can stash the insight into `insightLookup` and update `selectedInsightId`.

## 3. Data flow on each interaction

- **Mount**: `useLatestInsightSession` fires. When `latest.data.insights` arrives, a `useEffect` in `AIInsightsTab` sets `selectedInsightId` to `insights[0].id` IF `selectedInsightId` is still `null` AND `insights[0]` exists. Never clobber a later user pick.
- **Click today row**: `onSelect(id, fullInsight)` → parent merges into `insightLookup`, updates `selectedInsightId` → `InsightDetailPane` re-renders.
- **Click "Saved" header**: `Collapsible.onFirstExpand` fires → `useSavedInsights.refetch()` (first call only).
- **Click "Past Runs" header**: same pattern → `useSessionHistory.refetch()`.
- **Click a past-run session row**: lazy-fetch `GET /api/insights/sessions/{id}/insights`, cache by `sessionId` in `InsightSidebar` local state (mirror current `PastRunsSection`). Rendered insight rows under the session call `onSelect`.
- **Save toggle in detail pane**: `InsightCard`'s `SubscribeButton` invokes `onSaveToggle(id, next)` → `AIInsightsTab` sets `savedOverrides[id] = next` → sidebar row reads `effectiveSaved(id, fallback)` and shows the filled bell.

## 4. New files

- **`frontend/src/components/tabs/ai-insights/InsightSidebar.tsx`** — 320px left column.
  - Props: `todayInsights: LatestInsight[]`, `selectedInsightId: string | null`, `savedOverride: (id: string) => boolean | undefined`, `onSelect: (id: string, insight: LatestInsight) => void`.
  - Internal: three `Collapsible`s, past-run cache map keyed by sessionId, calls `useSavedInsights` and `useSessionHistory` (lazy via Collapsible onFirstExpand).

- **`frontend/src/components/tabs/ai-insights/InsightDetailPane.tsx`** — right pane.
  - Props: `insight: LatestInsight | null`, `session: LatestSessionRow | null`, `total: number | undefined`, `onSaveToggle: (id: string, next: boolean) => void`.
  - Wraps `InsightCard`. Empty-state placeholder when `insight` is null ("Select an insight").

- **`frontend/src/components/tabs/ai-insights/SidebarRow.tsx`** — single row primitive.
  - Props: `headline: string`, `selected: boolean`, `saved: boolean`, `onClick: () => void`.
  - Truncates headline to ~50 chars, optional saved bell glyph, selected accent (background + left border via `insightTokens`).
  - Used by all three groups.

- **`frontend/src/components/tabs/ai-insights/AIInsightsTab.tsx`**:

  - Replace with `<div style={{display:'grid', gridTemplateColumns: useNarrow ? '1fr' : '320px 1fr', gap: s.s5}}>` containing `InsightSidebar` + `InsightDetailPane`.
  - Add `selectedInsightId`, `insightLookup`, `savedOverrides` state.
  - Add a `useNarrow()` hook (simple `window.matchMedia('(max-width: 1024px)')`).
  - The sidebar+detail grid is mounted ONLY when `showSnapshot === true`. Header, banners, `SessionRunner` branch, and cold-start `EmptyState` remain wrapped in their current branches.

## 6. Responsive fallback

`useNarrow()` returns true when `window.matchMedia('(max-width: 1024px)').matches`. Listens to the `change` event in a `useEffect`.

When narrow:
- `gridTemplateColumns` becomes `'1fr'`.
- Sidebar renders above detail pane (natural source order).
- No max-height / no internal scroll on the sidebar.

## 7. Files NOT touched

- Backend, other tabs, type declarations, hooks (reused verbatim).
- `SnapshotInsightFeed.tsx`, `PastRunsSection.tsx`, `SavedInsightsSection.tsx` — left in repo for backward compatibility; just not rendered from `AIInsightsTab` anymore.

## 8. Risks & mitigations

- **Risk**: the two `<SessionRunner />` branches in `AIInsightsTab` (current lines 542–551 and 595–603) must still render full-width without a sidebar during a live SSE run.
  - **Mitigation**: sidebar+detail grid is only mounted when `showSnapshot` is true; live-runner and cold-start branches keep their existing full-width layout.

- **Risk**: `selectedInsightId` can go stale if a session refetch removes its target insight.
  - **Mitigation**: when `latest.data` changes, a `useEffect` checks whether `selectedInsightId` still resolves via `insightLookup` or `latest.data.insights`. If not, reset to `insights[0]?.id ?? null`.

- **Risk**: `savedOverrides` drifts from server truth on tab remount.
  - **Mitigation**: overrides are in-memory only; next mount rebuilds from `useSavedInsights` source of truth. Acceptable for demo.

# Reflection Reports

This folder stores archived daily reflection reports generated by the nightly analyst-improvement job.

## Intended filename pattern

Use a dated filename, preferably UTC-based for consistency, for example:

- `2026-05-07.md`
- `2026-05-07-reflection.md`
- `2026-05-07T0000Z-reflection.md`

## Preferred report structure

1. Executive summary
2. Product/data learned
3. Mistakes corrected or near-errors
4. New communication/presentation technique learned
5. Anti-hallucination rule changes
6. Habits to improve tomorrow

## Writing guidance

- Keep reports concise, evidence-driven, and practical.
- Prefer grounded observations over self-congratulation.
- Record specific failure modes and how to prevent them.
- If nothing material changed, say so briefly.
- Update long-term memory separately only for durable lessons.
